# 20. Thuật ngữ

| Thuật ngữ | Nghĩa trong VietHook Lab |
|---|---|
| Hook | Câu hát 4–8 nhịp hoặc clip 5–15s mang nhận diện bài |
| Post-chorus / chant | Lớp lặp sau chorus, thường ít lời, dễ cắt clip |
| Topline | Lời + giai điệu vocal |
| Tone Map | Hàng chip âm tiết + thanh + màu khớp melody |
| Tone Fit | Điểm khớp thanh điệu ↔ pitch (bigram + nội âm tiết) |
| Tone Engine | Module phân tích thanh, nguyên âm, coda, cảnh báo |
| Tone lock | Giữ lời, chỉ đổi melody |
| Lyric lock | Giữ melody, gợi ý đổi lời |
| Hook freeze | Giữ câu chính, biến thể phần còn lại |
| Similar motion | Hướng pitch cùng hướng chuyển thanh |
| Oblique motion | Một bên giữ, một bên chuyển |
| Contrary motion | Hướng pitch ngược chuyển thanh — rủi ro đảo nghĩa |
| Mất dấu | Tai nghe ra thanh/từ khác do melody |
| Luyến / slide / grace | Nốt phụ để thể hiện hỏi/ngã/huyền |
| Láy | Ornament dân gian, dễ sến nếu lặp dày |
| Melisma | Một tiếng nhiều nốt |
| Ngân | Sustain nguyên âm / coda mũi |
| Coda tắc | p t c ch — cắt hơi, khó ngân |
| Openness | Độ mở nguyên âm, ảnh hưởng nốt cao |
| Tessitura | Vùng giọng dễ hát |
| Peak | Cao điểm cao độ hoặc cảm xúc |
| Style pack | Bộ chord + rhythm + contour + vocab |
| Ngũ cung | 5 nốt: Cung Thương Giốc Chủy Vũ (Hò Xự Xang Xê Cống) |
| Hook Score | Rubric 0–100, 7 tiêu chí |
| Viral snippet | Cửa sổ 5–15s tự chứa nghĩa + motif |
| Beam search | Tìm melody: giữ k ứng viên tốt nhất từng bước |
| Lexicon | Từ điển âm tiết + thanh + vowel + coda |
| Corpus | Kho feature hook (không nhất thiết full audio) |
| Blind test | Nghe không biết đây là variant nào / của ai |
| Sing-back | Nhớ và hát/gõ lại sau 30s |
| Composition notes | Ghi chú phá luật có chủ đích |
